# 选股条件模板库

> ✅ 本模板与 SKILL.md 正文 Phase 1 五策略（S1-S5，v2.12.0 质量导向）保持一致。
> 若与正文冲突，以正文为准。

## 核心五策略（现行默认，S1-S5）

### S1 质量成长型（主力，圈定好生意）
```
ROE大于18% 市盈率大于0 市值大于150亿 A股
```
逻辑：高 ROE 是好生意的核心代理，不设 PE 上限，估值交给六关三情景估值。

### S2 价值质量型（好生意 + 合理价）
```
ROE大于15% 市盈率小于25 市盈率大于0 市净率小于5 市值大于150亿 A股
```
逻辑：质量门槛 + 估值不极端。

### S3 高股息防御型（底仓）
```
股息率大于4% 市盈率小于20 连续三年分红 市值大于200亿 A股
```
逻辑：现金流好 + 分红稳定，组合防御底仓（非全部）。

### S4 强势突破型（捕捉资金+趋势，防踏空）
```
今日涨幅大于2% 小于7% 成交额大于3亿 市值大于150亿 A股
```
逻辑：⚠️ 必须用"成交额"（mx-xuangu 把"成交量"解析为股数，>3亿股会解析失败）；不设 PE。

### S5 稳定成长型（覆盖中间地带，填补盲区）
```
ROE大于12% 市盈率小于30 市盈率大于10 市净率小于6 市值大于100亿 A股
```
逻辑：ROE 12-18%、PE 10-30 的稳定增长龙头；六关阶段另验近三年营收/利润连续增长（至少2年）。

## 执行约束（不可省）

- **顺序执行，间隔 sleep 3**，不可并行（并发 ≥3 触发 503）
- 先跑 mx-data 持仓查询，再跑五策略
- 失败重试 2 次仍失败 → 跳过该策略，用其余结果继续

## 条件调优规则

1. **候选太少（<3 只）**：优先放宽 S5 门槛（ROE>10%、市值>80亿），不放松 S1/S2 质量线
2. **候选太多（>30 只）**：收紧市值下限（+50亿），不加 PE 一刀切
3. **市场大跌日**：S3 防御权重提高
4. **市场大涨日**：S4 照跑但依赖 Phase 4.5 价格异动拦截（>7% 淘汰）

> ⚠️ 海选只圈"疑似好生意"，估值高低一律交给六关三情景估值，**海选不再用 PE 一刀切**（v2.12.0 起）。
