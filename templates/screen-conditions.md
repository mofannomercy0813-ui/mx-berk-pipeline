# 选股条件模板库

## 核心三策略（v2 默认）

### 策略A — 动量稳健型
```
今日涨幅大于1% 小于7% 成交量大于2亿 市盈率小于30 市盈率大于0 A股
```
逻辑：捕捉有资金流入但未暴涨的标的。涨幅上限7%排除追高风险。

### 策略B — 价值质量型
```
市盈率小于20 市盈率大于0 市净率小于4 ROE大于12% 涨幅大于-1% A股
```
逻辑：低估值+高盈利能力，当日未大跌。

### 策略C — 高股息防御型
```
股息率大于3% 市盈率小于25 连续三年分红 市值大于100亿 A股
```
逻辑：现金流好+分红稳定+大盘股。

## 扩展策略（按市场风格切换）

### 成长加速型（牛市/成长风格市场）
```
净利润增长率大于30% 营收增长率大于20% 市盈率小于40 A股
```

### 行业景气型（有明确行业热点时）
```
{行业名} 毛利率大于30% ROE大于15% 涨幅大于0% A股
```

### 技术突破型（趋势明确时）
```
今日涨幅大于2% 小于7% 成交量大于5亿 5日均线大于10日均线 市盈率大于0 A股
```

### 超跌反弹型（市场恐慌后）
```
近5日跌幅大于10% 市盈率小于20 ROE大于10% 市值大于200亿 A股
```

## 条件调优规则

1. **候选太少（<3只）**：放宽条件，如 PE<35、ROE>10%、涨幅>0%
2. **候选太多（>30只）**：收紧条件，如 PE<15、ROE>15%、成交量>5亿
3. **市场大跌日**：切换到防御型或超跌反弹型
4. **市场大涨日**：切换到价值质量型，避免追高
