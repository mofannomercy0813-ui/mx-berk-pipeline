# mx-berk-pipeline — A 股多策略选股投顾管线

> 多策略并行扫描 + 行业分散化约束 + Berkshire 六关快筛 → 每日操作建议

基于东方财富妙想 API 的 A 股每日选股管线。三组互补策略并行扫描全市场，经去重、行业分散化、Berkshire 六关量化快筛，最终输出结构化的买卖操作建议。附带 30 天模拟跟踪系统，用于验证策略有效性。

## 管线流程

```
多策略并行扫描（动量 + 价值 + 高股息）
    ↓ 去重 + 行业分散化（同行业≤2只）
CSV 数据粗筛（PE/PB/ROE）
    ↓ mx-data 财务数据拉取（串行 + 重试）
Berkshire 六关快筛 + 技术面验证
    ↓
结构化操作建议 + 30天模拟跟踪
```

## 三组互补策略

| 策略 | 类型 | 查询条件 | 目标 |
|------|------|---------|------|
| **A 动量稳健** | 趋势跟踪 | 涨幅 1%-7%, 成交量>2亿, PE 0-30 | 捕捉资金流入但未暴涨的标的 |
| **B 价值质量** | 基本面 | PE<20, PB<4, ROE>12%, 涨幅>-1% | 低估值 + 高盈利 |
| **C 高股息防御** | 现金流 | 股息率>3%, PE<25, ROE>15%, 连续三年分红, 市值>200亿 | 真实现金回报 + 盈利质量 |

## Berkshire 六关快筛

| 关卡 | 淘汰条件 | 量化阈值 |
|------|---------|----------|
| 1. 能力圈 | 无法说清生意本质 | — |
| 2. 好生意 | 毛利过低或持续下滑 | 毛利率 < 15% |
| 3. 护城河 | ROE 过低且无改善 | ROE < 10% |
| 4. 管理层 | 高杠杆或频繁减持 | 资产负债率 > 75% |
| 5. 安全边际 | 估值过高 | PE > 30 或 PB > 5 |
| 6. 镜子测试 | 5 句话说不清买入逻辑 | — |

> 补充淘汰：扣非净利润为负、ROE 趋势恶化、营收连续下滑均一票否决。

## 技术面确认

通过六关的候选需额外验证：

| 条件 | 通过标准 | 说明 |
|------|----------|------|
| 趋势 | 最新价 > 20 日均价 | 在上升趋势中 |
| 短期动量 | 5 日均价 > 10 日均价 | 短期均线多头排列 |
| 不追高 | 当日涨幅 < 7% | 避免追涨 |

> 技术面是加分项，不是硬性淘汰条件。基本面强但技术面弱的标的保留并标注「等待回调」。

## 前置条件

- Python 3.8+
- `pip install requests pandas openpyxl`
- 东方财富妙想 API Key：设置环境变量 `MX_APIKEY`
- 可选：WSL（用于 ai-berkshire 的 `financial_rigor.py` 精确财务验证）

## 安装与使用

```bash
# 克隆仓库
git clone https://github.com/YOUR_USERNAME/mx-berk-pipeline.git
cd mx-berk-pipeline

# 安装依赖
pip install -r requirements.txt

# 设置 API Key
export MX_APIKEY=your_api_key_here

# 运行三条策略线（可并行）
cd tools
python mx_xuangu.py "今日涨幅大于1% 小于7% 成交量大于2亿 市盈率小于30 市盈率大于0 A股"
python mx_xuangu.py "市盈率小于20 市盈率大于0 市净率小于4 ROE大于12% 涨幅大于-1% A股"
python mx_xuangu.py "股息率大于3% 市盈率小于25 ROE大于15% 连续三年分红 市值大于200亿 A股"

# 对候选股票拉取财务数据
python mx_data.py "600519 近三年年报 营收 净利润 毛利率 ROE 资产负债率"
python mx_data.py "600519 最新价 涨跌幅 5日均价 10日均价 20日均价 市盈率 市净率"
```

> 完整流程参见 [SKILL.md](SKILL.md)，包含行业分散化、Berkshire 快筛、30 天模拟跟踪的详细规则。

## 30 天模拟跟踪

管线附带模拟跟踪系统，用于验证策略有效性：

- **定时触发**：每日 11:30 / 13:30 / 14:20 自动运行
- **模拟买入**：13:30 确认后以当时价模拟买入，单只仓位 10%-15%
- **卖出条件**：建议变为卖出 / 持有超 15 日 / 亏损超 10%（止损）/ 盈利超 25%（止盈）
- **资金管理**：总资金 100 万，最多持仓 8 只，现金下限 20%

## 注意事项

- 这是一个**投顾建议管线**，不是量化交易信号
- 所有输出建议需人工确认后再执行实际操作
- mx-xuangu 和 mx-data 共享同一个 `MX_APIKEY` 调用配额
- mx-data **不可并发调用**（超过 2 个同时查询会触发错误），需串行执行
- CSV 输出默认路径：`C:\root\.openclaw\workspace\mx_data\output\`（Windows）
